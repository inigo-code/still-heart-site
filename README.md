# Still Heart

![Still Heart showing one album as a grid of pictures](https://heartapps.github.io/still-heart/assets/stills_preview-wide.webp)

Website and downloads for Still Heart, one of the [Heart Apps](https://heartapps.github.io/). Download the app from [Releases](../../releases/latest).

The site is plain HTML and CSS, served by GitHub Pages. heart.css and heart.js are the shared Heart Apps files. The apps are free, all rights reserved.
